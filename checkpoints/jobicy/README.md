# Jobicy executable

The command is implemented in Idriç under
[`examples/autogenerated/jobicy-cli`](../../examples/autogenerated/jobicy-cli).
Its HTTP requests use the shared Idric-Net and ICU response interfaces recovered
from [dilapidated-shed/idric-cli PR #8, “Finish the Idriç Indeed CLI”](https://github.com/dilapidated-shed/idric-cli/pull/8). No service
credentials are read or sent. The ICU native library is compiled by pinned ICK.

## Commands

`jobicy help`, `jobicy version`, `jobicy doctor`, `jobicy locations`,
`jobicy industries`, `jobicy url`, `jobicy search`, `jobicy status ID...`, and
`jobicy fixture FILE` are executable commands. Search accepts `--count` (1–200,
default 20), `--geo`, `--industry`, `--tag`, and opaque `--cursor`. Output can be
selected with `--format tsv` or `--format jsonl`.

`--all` follows sequential cursor pages, with the same filters and page size.
The default bound is 100 requests; `--max-pages` permits 1–1000. A repeated
cursor, inconsistent pagination, conflicting copies of an ID, failed page, or
exhausted bound returns nonzero and withholds complete-feed output. A successful
single page is labelled PAGE_ONLY when continuation remains. Starting with a
cursor is labelled CONTINUATION and cannot establish coverage of the omitted
prefix. Applied filters and page counts are checked against each request.

All accepted IDs retain their exact decimal digits, including integers beyond
binary64's exact range. Full HTML descriptions, entities, tabs and newlines are
preserved. TSV escapes backslash, tab, CR, LF and other control characters;
`jobType` and `jobIndustry` are JSON arrays inside their TSV fields. Missing
salary values are `null`; present currency/period text uses JSON string quoting
in TSV to distinguish it from absence. JSONL preserves numeric IDs and salary
integers without floating-point conversion. It includes original Jobicy field
names plus source, provenance, observation time, request URL and API version.

Status accepts 1–100 positive integer IDs before duplicate removal. It checks
the returned exact IDs, count, order and three-value status domain. `unknown`
never means `closed`, and disappearance from the feed proves no status change.
Location/industry taxonomy results retain their exact IDs, names and filter
slugs. Fixture output always carries offline provenance.

`--evidence-dir` names an existing parent directory. The program creates a
distinct run directory containing each request URL, original public response
and observation/HTTP metadata. No commercial authorization is available.
`search --sync --evidence-dir DIRECTORY` uses a persistent start marker and
exclusive directory lock to enforce at least one hour between automated passes.
A failed pass retains the marker; an interrupted lock requires inspection.
No scheduled synchronization is installed. Ordinary search/status commands are
manual operations. Public feed responses may be cached for one hour and status
responses for 60 seconds; this initial CLI does not serve an application cache.
HTTP 429 causes a distinct throttling exit and no automatic tight retry.

The API covers seven recent publication days with a delay; it is not a nationwide
employment census. Geographic eligibility remains the provider's text. Remote
does not mean permission to work from every country.

## Build and install

[`source-pins.tsv`](source-pins.tsv) records compiler, JSON, networking and native
toolchain source revisions. Kitchen owns `tasks/jobicy-cli/1.grease` with distinct
preflight/build/install/test operations. The compiler uses its maintained Chez
backend; the native ICU and acceptance verifier builds use ICK. The small C
qualification program contains Icky assignment syntax and rejects a stock-C
compiler substitution. This C slice uses no atomic builtins; GCC 17's automatic
libatomic linkage is explicitly disabled with `-fno-link-libatomic`.

Provision dependencies separately on the build host: bootstrap the pinned Idriç
compiler, install `contrib` from the pinned JSON repair, install the pinned
Idric-Net `idric-net.ipkg` and ICU `icu-response.ipkg` into the same compiler
prefix, and build the pinned ICK C-only stage. Consumer compilation installs
nothing and refuses source pin mismatches.

Set verified absolute paths for `IDRIC_ROOT`, `IDRIC_JSON_ROOT`,
`IDRIC_NET_ROOT`, `ICU_ROOT`, `ICK_SOURCE_ROOT`, `IDRIC`, `IDRIS2_PREFIX`, `CHEZ`,
`ICK`, `KITCHEN_ROOT` and `GREASE`. A driver used before installation also needs
`ICK_DRIVER_DIR`; the executed host used `HOST_LIBGCC_DIR` for its explicitly
declared GCC-13 runtime archive, not as a substitute compiler.

Run `make -C ABSOLUTE_CLI_ROOT jobicy`, then
`make -C ABSOLUTE_CLI_ROOT install-jobicy PREFIX=ABSOLUTE_PREFIX`.
Set `JOBICY_PROGRAM=ABSOLUTE_PREFIX/bin/jobicy` and run
`make -C ABSOLUTE_CLI_ROOT jobicy-test`. The procedure runs the installed command
outside the checkout and validates the installed source digest.

This is an actual host installation using the pinned Chez runtime and ICU
library. Its generated executable and application directory retain the declared
host runtime path. A portable standalone distribution is not claimed. Android
ARM32 A1 and ARM64 C67 remain separate NOT_RUN targets; build tools are not
installed on either device.

## Acceptance

The installed regression suite executes 55 labelled cases plus byte-for-byte
description comparisons, exact request-target checks and deduplication checks.
It uses a compiled generic Idriç loopback fixture server to exercise ICU.
Independent ai-ci `jobicy/status.contract.tsv` compares executed status output
with its separately owned oracle and rejects an unknown-to-closed mutant.

Flexible Pipes opens the original assignment through `jobicy-cli-open` and
closes the exact source heads through `jobicy-cli-acceptance`, including Kitchen
build/install/test, ai-ci, artifact digests and a distinct live-provider stage.
Its executed receipts are authoritative. Synthetic data and loopback HTTP are
not provider evidence. The first installed live attempt on this restricted
container exited 5 because ICU could not connect; it returned no postings and
must not be described as an empty successful search. The host has no direct
network route and supplies an HTTPS proxy. ICU's pinned proxy repair establishes
an HTTP CONNECT hop while retaining origin certificate/hostname verification.
The installed native client then returned three actual USA-eligible Jobicy
postings without credentials. Final source-bound provider, status and cursor
evidence belongs in the Flexible Pipes receipt; the initial failure remains
historical evidence rather than an outstanding transport blocker.

Exit codes: 2 arguments; 4 HTTP/API rejection; 5 transport; 6 malformed/schema
response; 7 file/evidence I/O; 8 throttling/sync guard; 9 pagination/inconsistency.
