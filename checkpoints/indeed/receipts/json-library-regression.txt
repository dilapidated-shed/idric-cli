The original JSON string-token decoder interpreted lowercase d as 45 instead
of 13, so the UTF-16 code unit 002d became 77 (M) instead of 45 (-). Decoded
credential comparison therefore could not recognize the escaped token.

The maintained JSON library now decodes both cases correctly and validates
high/low surrogate pairs before constructing Unicode characters. The Idriç
acceptance program covers lower/uppercase hex, BMP characters, supplementary
characters and malformed/isolated surrogate refusal. The inherited BMP
round-trip test (all scalar values 0 through 55295) returned [].
